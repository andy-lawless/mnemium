# Mnemium

Mnemium is the `mn` skill. Notes live in one cloud-drive folder. This repo is the skill.

Load `SKILL.md` when the user types `/mn`, asks to save or recall a note, excerpt, diagram, or asset, or the current work should be captured or checked against a saved topic.

The vault path is `~/.config/mnemium/config.json`. `scripts/mn.js` is the only writer. Symlinks: `~/.cursor/skills/mn` and `~/.claude/skills/mn`.
